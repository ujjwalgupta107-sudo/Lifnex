## 1. Asset Directory Overview

The folder `demo-assests/` located in the root of the project contains primary branding elements, UI/UX reference designs, and visual concepts. Under Phase 1 requirements, these original assets are strictly preserved without any rename, delete, move, or overwrite operations.

When frontend development begins in Phase 2, optimized and web-standard copies will be mirrored to the frontend distribution directory (e.g., `frontend/assets/`), leaving `demo-assests/` completely untouched as the single immutable source of truth.

## 3. Asset Utilization Rules & Governance

1. **Preservation**: The original folder name `demo-assests/` and all 8 files must remain unmodified in place.
2. **Logo Implementation**: `Lifnex AI Blood Donor Network Logo use this logo in website.png` will be exported into optimized web formats (e.g. transparent web-ready PNG, standard 32x32 / 16x16 favicon, and responsive header logo) in `frontend/assets/images/logo/` during Phase 2.
3. **UI/UX Grounding**: `ui and ux idea 1.png` and `ui and ux idea 2.png` dictate the visual direction:
   - Deep medical crimson (`#DC2626` / `#B91C1C`) paired with slate dark mode and clean sterile light mode.
   - Prominent map-first split view for emergency dispatch.
   - Glassmorphic metric cards and pill-shaped status badges.
4. **No Replacement Without Cause**: No external or placeholder stock art will be introduced when an existing asset from `demo-assests/` already fulfills the structural or narrative purpose.
